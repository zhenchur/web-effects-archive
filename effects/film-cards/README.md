# Film Cards

Два варианта карточной галереи по визуальному референсу [Motion Gallery: Film](https://motion.dev/examples/react-gallery-film):

- **Эффект 3:** перетаскивание мышью/пальцем, выбор карточки или её подписи кликом, клавиши ← / → / Home / End.
- **Эффект 4:** разворот карточек по прокрутке внутри закреплённой секции; обратная прокрутка точно возвращает предыдущие состояния.

Центральная карточка показана фронтально. При смене кадра уходящая карточка поворачивается от 0° к 60°, а входящая в это же время раскрывается от 60° к 0°. В середине перехода обе остаются заметно повёрнутыми. Горизонтальное движение рассчитано отдельно: расстояние между центрами пары меняется, создавая просвет между карточками во время передачи центра. В установившемся ряду боковые карточки могут перекрывать друг друга; постоянный зазор на всём пути не задаётся.

Боковая карточка достигает глубины около `.6` своей ширины; дальше карточки перемещаются вбок при постоянных угле и глубине. Дополнительный `scale` не применяется. Карточки имеют пропорции `12 / 5`; ориентир ширины фронтальной карточки на десктопе — 43% сцены.

При отпускании drag карточки доводятся до целого индекса; короткий быстрый жест учитывает скорость. Выбор кликом или клавиатурой использует переход около `.7` секунды с кривой cubic-bezier `.22, 0, .23, 1`. Отдельных задержек между поворотом и перемещением нет. Последовательность ограничена первым и последним кадром, без бесконечных копий.

Это самостоятельная реализация на TypeScript, CSS 3D и GSAP 3.15.0. Исходники и компоненты Motion+ не используются. Геометрия и характер движения приближены по [публичному видеопревью Motion](https://images.motion.dev/examples/stage/react/gallery-film/v-c6bd4d60dc3e/thumb.mp4), включая измерения положения и перспективы карточки по кадрам. Доступ к интерактивному примеру и его исходникам ограничен Motion+, поэтому выбранные параметры не выдаются за оригинальные настройки. [Разбор движения и границы точности](MOTION.md). Открытие полноэкранного detail-view не входит в этот эффект.

## Подключение

```ts
import { createFilmCards, FILM_CARDS } from './effects/film-cards';
import './effects/film-cards/style.css';

const gallery = createFilmCards(host, {
  cards: FILM_CARDS, // либо собственный массив { src, title, subtitle?, alt? }
  mode: 'drag',
  initialIndex: 3,
});

// При удалении секции / смене маршрута:
gallery.destroy();
```

`host` — реальный контейнер галереи. В режиме `drag` модуль имеет собственную адаптивную высоту; режим `scroll` заполняет высоту хоста. Предки не должны обрезать весь закреплённый контейнер через `overflow: hidden`. Обрезка боковых карточек уже предусмотрена внутри галереи.

## API

| Параметр / метод | Значение |
| --- | --- |
| `cards` | Непустой массив карточек. Текст задаётся через `textContent`; HTML в названиях не исполняется. |
| `mode` | `drag` (по умолчанию) или `scroll`. |
| `initialIndex` | Начальная позиция, по умолчанию 0. |
| `label` | Доступное название галереи. |
| `reducedMotion` | Необязательное переопределение; обычно следует оставить системную настройку. |
| `setProgress(0…1)` | Только `scroll`: от первого до последнего кадра. Значение ограничивается диапазоном. |
| `select(index, animate = true)` | Выбор кадра из внешнего кода. Следующий `setProgress` возвращает управление scroll-хосту. |
| `refresh()` | Пересчитать геометрию. Размеры также отслеживаются через `ResizeObserver`. |
| `destroy()` | Остановить tween, убрать DOM, pointer/keyboard/media listeners и observer. Повторный вызов безопасен. |

В режиме `scroll` модуль не слушает колёсико, не фиксирует страницу и не импортирует код архива. Внешняя интеграция передаёт реальный прогресс прокрутки; положение, поворот и глубина вычисляются по той же геометрии, что и в режиме `drag`. Временной easing выбора кадра здесь не применяется: обратная прокрутка точно проходит прежние положения. Для существующего архива используется его sticky-секция и Lenis; отдельно подходит нативный scroll или ScrollTrigger.

```ts
const gallery = createFilmCards(host, { cards: myCards, mode: 'scroll' });

// section содержит .viewport с position: sticky; top: 0; height: 100svh.
// section.style.height = `${viewportHeight + travel}px`;
// На scroll:
gallery.setProgress((window.scrollY - sectionStart) / travel);
```

Не вычисляйте `sectionStart` и `travel` на каждом кадре: обновляйте их при resize и изменении макета. Не добавляйте второй сглаживатель поверх Lenis. В `examples/film-cards.html` находится полный пример обеих интеграций без Lenis.

## Доступность и поведение

- Вертикальная прокрутка пальцем сохраняется (`touch-action: pan-y pinch-zoom`); горизонтальный жест управляет галереей.
- Click после drag подавляется. `pointercancel`, потеря захвата и уход фокуса завершают жест.
- Клавиатура работает на сцене и кнопках выбора; текущая кнопка помечена `aria-current`.
- При `prefers-reduced-motion: reduce` карточки становятся статичной сеткой: без перспективы, автопроигрывания, долгого закрепления и инерции. Scroll-хост должен также убрать искусственную длину секции (архив и standalone уже это делают).
- В кадре меняются только transform, затемнение и порядок карточек. Измерения геометрии выполняются при `refresh`.

Рендер переиспользует объект геометрии каждой карточки и записывает составной `translate3d(...) rotateY(...)` одним присваиванием `style.transform`; затемнение и `zIndex` обновляются через GSAP `quickSetter` только при изменении. Кадр с прежними позицией, шириной и режимом reduced motion пропускается. Переходы выбора используют один переиспользуемый GSAP `quickTo` для общей позиции с прежними длительностью `.7 с` и кривой; после ручного перемещения его начальная позиция задаётся явно. При передаче управления жесту или прокрутке tween ставится на паузу, при `destroy()` удаляется. Геометрия движения и публичный API сохранены. Модуль полностью управляет `transform` внутренних `.film-card`: не анимируйте его извне; для дополнительного движения всей галереи используйте внешнюю обёртку.

## Переносимый ZIP

`npm run build` создаёт `public/downloads/film-cards.zip`, `.js` и `.css`.

ZIP включает TypeScript, CSS, фотографии, лицензионные сведения, разбор движения `MOTION.md` и готовое `demo/index.html` с двумя вариантами. Собранный ES-модуль содержит GSAP и демонстрационные изображения; внешние запросы для демо не нужны. Для локального запуска распакованной папки:

```sh
npm install
npm run dev
```

Для приложения с собственными карточками можно импортировать `createFilmCards`, не используя `FILM_CARDS`; Vite удалит неиспользуемые демонстрационные данные при tree-shaking. Источники фотографий перечислены в [ASSETS.md](ASSETS.md).
