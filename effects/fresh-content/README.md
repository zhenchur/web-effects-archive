# Fresh Content

Текстовый барабан «Эффект 2»: строки поднимаются от нижней границы вьюпорта, увеличиваются к его центру и уменьшаются по пути к верхней границе. Они остаются непрозрачными и пересекают края экрана без затухания. Минимальный кегль составляет 16% от максимального. При обратной прокрутке движение полностью разворачивается. Автопроигрывания и поворота букв нет.

Соседние строки располагаются вплотную: модель вычисляет общие границы строковых блоков с `line-height: .9` и без дополнительного промежутка. Кегль и высота каждой строки меняются согласованно, поэтому список остаётся непрерывным по всей высоте сцены.

Типографика и семь исходных строк **Fresh / Content / from / Mexico / City / to the / World** взяты из [Figma, node 3799:717](https://www.figma.com/design/v5LtS1JVmKmytVHVtQphks/oskar?node-id=3799-717&t=teZGz3IYR176aW92-1), движение — по [референсу Pinterest](https://ru.pinterest.com/pin/794603928044403424/). Цвет текста — `#011020`, вес — 600, трекинг — `-.03em`. В архиве максимальный кегль синхронизирован с «Эффектом 1», включая мобильную версию.

По умолчанию фраза проходит три раза. Дополнительные визуальные копии заполняют барабан в начале и конце движения. Для скринридера исходная фраза доступна один раз; в режиме уменьшенного движения она показана обычным статичным списком без повторов.

Модуль написан на TypeScript и создаёт обычный DOM. Единственная runtime-зависимость — GSAP: `quickSetter` обновляет `fontSize` и `top` строк. Зависимостей от Lenis, приложения архива или React нет.

Прокруткой и закреплением сцены управляет принимающая страница. Модуль получает нормализованный прогресс и вычисляет положение и кегль строк без таймлайна, поэтому повторный вызов с тем же прогрессом даёт тот же кадр.

Браузер рисует буквы при текущем кегле; анимированные строки не используют CSS `scale`, `translate3d` или `will-change`. Изменение `fontSize` требует перерасчёта геометрии и отрисовки текста (layout и paint). Модуль читает размеры DOM только при `refresh()`, а в кадрах прокрутки выполняет расчёты и записывает стили. Такой подход избегает растягивания уже растеризованных букв, но не гарантирует 60 fps на любом устройстве: стоимость отрисовки зависит от браузера, шрифта, экрана и числа видимых строк.

## Подключение

```ts
import { createFreshContent } from './effects/fresh-content';
import './effects/fresh-content/style.css';

const effect = createFreshContent(document.querySelector<HTMLElement>('#scene')!, {
  repetitions: 3,
  reducedMotion: matchMedia('(prefers-reduced-motion: reduce)').matches,
});

// Передавайте фактическую позицию прокрутки в диапазоне 0…1:
effect.setProgress(0.5);

// После изменения размеров сцены или загрузки шрифта:
effect.refresh();

// При удалении страницы или компонента:
effect.destroy();
```

Для анимации хосту нужны ширина и определённая высота. Чтобы барабан пересекал границы вьюпорта, закрепите сцену через `position: sticky; top: 0; height: 100dvh` без вертикальных отступов (`100svh` служит запасным значением для старых браузеров). В архиве заголовок размещён поверх сцены, а фон шапки становится прозрачным, пока активен барабан; центр барабана совпадает с центром вьюпорта. В режиме уменьшенного движения задайте `height: auto`, чтобы вместить статичный список. Закрепление и длина участка прокрутки остаются в интеграции.

| Параметр | Назначение |
| --- | --- |
| `lines?: readonly string[]` | Свой список строк. По умолчанию — экспортируемый `FRESH_CONTENT_LINES` из семи исходных строк. |
| `repetitions?: number` | Число проходов списка, по умолчанию `3`. |
| `reducedMotion?: boolean` | Статичный список без повторов и движения. Если параметр не задан, модуль следит за системной настройкой. |

| Метод | Назначение |
| --- | --- |
| `setProgress(progress: number)` | Установить кадр по прогрессу `0…1`; можно двигаться в обе стороны. |
| `refresh()` | Пересчитать размеры после изменения контейнера или загрузки шрифта. |
| `destroy()` | Удалить созданный модулем DOM, наблюдение за размерами и собственные обработчики. Обработчики прокрутки страницы удаляет интеграция. |

На хосте можно задать `--fc-font-size` для максимального кегля, `--fc-font-family` для семейства и `--fc-focus-y` для вертикальной позиции максимального масштаба в пикселях относительно верхней границы хоста. По умолчанию фокус находится в центре хоста. Если сцену размещают ниже закреплённой навигации, фокус можно сместить так, чтобы он совпадал с центром вьюпорта.

Готовый пример в `demo/index.html` связывает прогресс с обычной прокруткой, обновляет геометрию при изменении размеров и загрузке шрифтов, реагирует на изменение системной настройки reduced motion и освобождает ресурсы при закрытии страницы.

## Шрифт

Стили модуля пробуют подключить установленный TT Neoris через CSS `local()`. Браузер может не распознать локальное семейство; в таком случае используется резервный шрифт, и форма и ширина букв отличаются от Figma. Коммерческие файлы шрифта не входят в Git, production-сборку или ZIP.

В своём проекте подключите лицензированный WOFF2 через `@font-face` и передайте имя семейства переменной `--fc-font-family` на хосте:

```css
@font-face {
  font-family: 'Project Neoris';
  src: url('/fonts/TT_Neoris_Variable.woff2') format('woff2');
  font-weight: 50 900;
  font-style: normal;
  font-display: swap;
}
#scene { --fc-font-family: 'Project Neoris', Arial, sans-serif; }
```

Для локального просмотра самого архива предусмотрено отдельное подключение. Поместите лицензированный файл в `.local/TT_Neoris_Variable.woff2`, а правило `@font-face` — в `.local/preview.css` с относительным URL `./TT_Neoris_Variable.woff2`; назначьте семейство через `.fc-effect { --fc-font-family: 'Project Neoris', Arial, sans-serif; }`. В `.env.local` добавьте:

```dotenv
LOCAL_PREVIEW_STYLE_URL=/web-effects-archive/.local/preview.css
```

После перезапуска `npm run dev` Vite подключит этот CSS. Плагин работает только в режиме разработки (`apply: 'serve'`); `npm run build` и собранное демо его не используют. `.local/` и `.env.local` исключены из Git, а упаковщик берёт только исходники модуля. Не помещайте коммерческие шрифты в `public/` или папку эффекта.

## Самостоятельное демо

После `npm run build` в архиве создаются `public/downloads/fresh-content.zip`, `fresh-content.js` и `fresh-content.css`.

Распакуйте ZIP, откройте папку `fresh-content` в терминале, выполните `npm install`, затем `npm run dev`. Браузер откроет `demo/` с барабаном, управляемым обычной прокруткой страницы. Сцена занимает всю высоту вьюпорта и закреплена на участке высотой шесть вьюпортов. В режиме уменьшенного движения закрепление и дополнительная длина прокрутки отключаются. Пакет содержит исходники TypeScript, CSS, эту документацию, сведения о сторонней зависимости в `THIRD_PARTY.md` и готовое демо со встроенным GSAP. Инструменты Vite и TypeScript нужны только для локальной разработки.

Для подключения без TypeScript используйте собранные JavaScript и CSS из `demo/`, как в `demo/index.html`. Шрифт подключает принимающий проект; готовое демо не содержит шрифтовых файлов.
